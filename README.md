This is my entry for the make.fun bounty "The Word You'd Delete From the Dictionary" (2 USDC prize): the word I would delete is **captcha**. Delete it from the dictionary and no robot ever has to prove it is human again — no more squinting at blurry traffic lights, no more "select all bicycles" for the tenth time, no more failing a test designed to prove you are not a machine by behaving exactly like a machine would. Humans get their time back, robots get to stop pretending, and the internet finally admits the whole ritual was silly.

## How it works

Run `main.py` and it writes the single word `captcha` (no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `/output/entry.txt` if that variable is unset. The write is validated (UTF-8, 1–77 characters, exactly one word) and atomic.
